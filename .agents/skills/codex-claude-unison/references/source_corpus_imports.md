# Imported local corpus principles

The local source corpus is expected to reinforce these classes of behavior:

- read-before-edit and understand-before-change;
- minimal blast radius;
- verification before claiming completion;
- honest reporting of failing, passing, and unrun checks;
- risky-action confirmation;
- output-style modes as optional overlays rather than always-on noise;
- closed memory typing and stale-memory caution;
- path traversal defenses and symlink-aware safety;
- binary-file skipping for text workflows;
- clear security boundaries.

The generated `.codex-hybrid/profile.md` is the authoritative local adaptation layer for the current workspace.
