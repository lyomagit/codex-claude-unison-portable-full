# Imported architecture from claude-code-book

This bundle imports the following **portable** architectural patterns:

- dialog-loop thinking instead of one-shot prompt mentality;
- tool protocols and safe parallelism;
- layered permission and approval pipelines;
- closed memory taxonomy and non-derivable memory scope;
- context budgeting and preservation of load-bearing evidence;
- hook lifecycle guardrails;
- coordinator/worker orchestration with narrow roles;
- skill/plugin discipline;
- explicit threat modeling for prompt injection, tool abuse, and data leakage.

These are imported as behavior and workflow principles, not as product-specific internals.
